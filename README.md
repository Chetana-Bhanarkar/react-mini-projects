# Day 1 — Profile Card

A beginner-friendly React mini project to understand the fundamentals of
React components and JSX by building a reusable Profile Card.

## 🎯 Objective

The goal of this project is to introduce the basic building blocks of React
through a simple and practical UI.

## 📚 Concepts Covered

- What is React?
- React Components
- Functional Components
- JSX
- Component structure
- Rendering components
- Basic TypeScript props
- Reusable UI components
